# 你的 Open Duck Mini v2 建造清單
所有項目從未完成開始，請依自己的實測填寫。

## 版本與材料
先核對自己的零件；此清單從零開始。

- [ ] 確認採用 Open Duck Mini v2
  記錄上游版本；本站 CAD 基於 b23317a485b3cec7d8417f352478778b3475173c。

- [ ] 點收舵機與電控材料
  本次採 7.4V STS3215 系列，14 顆關節＋1 顆備品；依官方 BOM 核對電源與版本。

- [ ] 批次 0 小件試配
  先印 leg_spacer、roll_motor_top、roll_motor_bottom；確認嵌件、軸承與舵機配合。

- [ ] 核對熱熔嵌件尺寸與孔位
  本次 spacer 使用 M3、外徑 4.5 mm、長 5 mm，每件四顆。較淺的孔另量深度；Ø6 大孔不是嵌件孔。

## 舵機驗收
電性、位置與人耳異音分開記錄，不以沒有回報異常取代檢查。

- [ ] 逐顆記錄電壓、溫度、位置與電流
  單顆測試並編號，保留原始量測；先空載，再裝盤複測。

- [ ] 逐顆確認運轉聲音
  明確記錄有無異音；未聽測的維持未完成。

- [ ] 設定 ID、歸零並安裝舵盤
  右腿 10–14、左腿 20–24、頭頸 30–33；備品保留 ID 1。方向以官方設定表與組裝圖為準。

- [ ] 裝盤後複測並排除機械夾緊
  中心螺絲不能使舵機受阻；記錄調整前後的電流與到位結果。

## 右腿組裝
左右薄板不同且有方向性。一體件 v1／v2 為實驗改版，尚未實物驗證。

- [ ] 點收批次 1 列印件
  含 trunk_bottom 共 13 PLA＋1 TPU；件數見下方表格。

- [ ] 組裝右腳與踝舵機 ID 14
  依官方圖確認驅動板面朝 foot_top，PLA／TPU 腳底配合。

- [ ] 試配並組裝小腿
  兩款薄板各一片＋spacer；先接踝線並穿過指定薄板開口，確認方向再鎖緊。

- [ ] 試配並組裝大腿
  同樣用兩款薄板＋spacer，連接 ID 12 與 ID 13；髖 pitch 朝向依官方零位。

- [ ] 組裝右髖座並確認軸承配合
  ID 10 下方主動舵盤接 roll_motor_top；top 與 bottom 支承 ID 11。bottom 凸軸接 6804ZZ 內圈。

- [ ] 完成靜態干涉與線路檢查
  確認解除扭力後輕移關節；不強推止點，檢查夾線、卡點、鬆動與裂損。

## 電源與電控
本站目前沒有驗證完成的通用電池接線方案。依實際板型與官方資料核對。

- [ ] 確認電池、BMS、充電器匹配與接線
  辨識每個板子的實際端子、極性與額定規格，不能只按相似外觀照接。

- [ ] 記錄電池與穩壓輸出量測
  接入主控前量測並確認極性與額定輸出，保留數值。

- [ ] 準備 Pi、驅動與推論環境
  依官方 Runtime 說明安裝；記錄版本並確認 Adapter 能辨識。

- [ ] 固定機構後進行單腿小幅測試
  逐顆確認 ID 與方向，依實測設定供電限制；本站尚未完成此階段。

## 全機與驗證
後續流程為規劃，本站尚未完成全機行走驗收。

- [ ] 完成左腿與頭頸總成

- [ ] 全機接線、校正與逐關節測試
  先核對回應與方向，再進行姿態校正，記錄版本及結果。

- [ ] 完成站立與行走驗收
  依官方流程，保留可重現的參數、環境與測試結果。
